# Screenshots Placeholder Guide

Add real project screenshots to this folder before public portfolio sharing.

Recommended files:
- `dashboard.png`
- `tickets-list.png`
- `ticket-detail-ai.png`
- `knowledge-base-list.png`
- `knowledge-base-detail.png`
- `job-processing-status.png`
- `realtime-updates.png`
- `swagger-docs.png`

Capture tips:
- Use seeded demo users and safe fake data only.
- Avoid exposing tokens, secrets, local machine usernames, or private paths.
- Prefer 16:9 screenshots at readable resolution.
- Include key states: queued job, processing, completed, and fallback behavior.
